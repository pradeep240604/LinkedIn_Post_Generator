LinkedIn Post Generator 🚀

An AI-powered LinkedIn Post Generator built using Generative AI, LangChain, and the Groq API to create professional, engaging, and high-quality LinkedIn content instantly.

This project helps users generate optimized LinkedIn posts based on topics, achievements, projects, or experiences with improved structure, readability, tone, and hashtags.

---

✨ Features

- 🤖 AI-powered LinkedIn post generation
- ⚡ Ultra-fast response generation using Groq API
- 🔗 Built with LangChain framework
- ✍️ Professional and engaging content creation
- 🏷️ Smart hashtag generation
- 🎯 LinkedIn-focused post formatting
- 🧠 Prompt engineering for better output quality
- 📄 Clean and structured UI

📌 Project Objective

The goal of this project is to simplify professional content creation using AI by generating impactful LinkedIn posts with proper tone, structure, and engagement optimization.

This tool can help:

- Students
- Developers
- Job seekers
- Professionals
- Content creators
- Personal branding enthusiasts

---

🚀 How It Works

1. User enters a topic or idea
2. LangChain processes the workflow
3. Groq-powered LLM generates the content
4. AI optimizes formatting and readability
5. Final LinkedIn-ready post is displayed

⚙️ Installation

1️⃣ Clone the Repository

git clone https://github.com/pradeep240604/LinkedIn_Post_Generator.git

2️⃣ Navigate to Project Directory

cd LinkedIn_Post_Generator

3️⃣ Install Dependencies

pip install -r requirements.txt

4️⃣ Add Environment Variables

Create a ".env" file and add:

GROQ_API_KEY=your_api_key_here

5️⃣ Run the Application

python app.py
